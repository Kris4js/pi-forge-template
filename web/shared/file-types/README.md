# Shared file type icons

此目录存放跨前端消费的文件类型图标，统一入口为 `index.ts` 导出的 `fileTypeIcons`。

这些文件从已移除的旧版 Vue 前端（`frontend/src/assets/workflow-icons/`）迁移而来，供知识库文档、智能体生成文件卡片和文件预览等非工作流节点场景使用；普通工作流节点图标仍保留在原目录。

图标源自开源项目 [coze-studio](https://github.com/coze-dev/coze-studio)（coze-dev Authors，Apache License 2.0），原始路径为 `docker/volumes/minio/default_icon/`。依据 Apache 2.0 许可证条款复用并保留此来源声明。
