# 对比分析

## 分析目标

1. **给出准确的排名**：不只是按绝对值排序，还要考虑相对指标（份额、增速），避免"大而不强"的对象被误判为"好"
2. **识别结构性差异原因**：排名差异背后往往是品类结构、客单价等结构性因素，不能简单归结为"谁做得好"
3. **控制展示密度**：对比对象多时，排名图表要能突出重点而不是罗列全部

## 处理约束

- **不用绝对值单独下结论**：销售额最高不代表经营最健康，必须结合同比/环比增速一起看
- **不对差距很小的排名做绝对化表述**：5% 以内的差距应描述为"基本持平"，避免因数据小幅波动造成误导性结论
- **口径不一致时不能强行对比**：统计周期或计算方式不同的对象，应判定为"不可比"并在结论中说明，而不是硬凑一个排名

## 最佳实践

### 先分清横向还是纵向对比
横向对比是同一时间点不同渠道/门店/品类之间比，纵向对比是同一对象不同时间周期之间比，两种对比的口径统一方式不一样，分清楚再算，避免中途混淆。

### 口径统一是排名可信的前提
参与对比的对象在统计周期、是否含税、是否扣除退货上必须一致，不一致时要先在结论里说明差异，而不是让用户自己发现口径问题后来质疑整份报表。

### 排名要配上相对指标
市场份额占比、同比增速、环比增速要和绝对值一起呈现，例如"渠道 A 销售额最高"但如果它份额在下滑、渠道 B 份额在提升，这个信息比单纯的排名更有决策价值。

### 识别并说明结构性差异
排名靠前如果是因为品类结构不同（比如高客单价品类占比更高），要把这个原因作为补充说明附在排名之后，避免用户把结构性差异误读成运营效率差异。

## 判断标准

| 情况 | 处理方式 |
|---|---|
| 对比对象 > 8 个 | 只展示 Top N + "其他"汇总 |
| 相邻排名差距 < 5% | 描述为"基本持平"，不做绝对化表述 |
| 统计口径不一致 | 判定为"不可比"，明确说明，不强行给结论 |

## 输出格式

```
### 排名结果
1. 对象名称：绝对值 X | 份额 Y% | 同比/环比 Z%
2. ...

结构性差异说明（如有）：
排名靠前的对象是否因品类结构/客单价等结构性因素

口径说明（如涉及）：
是否存在不可比的对象及原因
```

## 示例

### 示例 A：份额提升但排名依然靠后

**场景**：拼多多渠道销售额排名第四（垫底），但份额环比提升 2 个百分点，同期京东份额下滑。

**输出示例**：
> 渠道销售排名：京东（7.2 亿，占比 45%，环比 -3pp）> 天猫（4.1 亿，占比 26%，环比持平）> 抖音（1.2 亿，占比 8%，环比 +1pp）> 拼多多（0.9 亿，占比 6%，环比 +2pp）。虽然拼多多排名仍垫底，但份额环比提升幅度在四个渠道中最高，京东份额有所回落，建议关注渠道结构变化趋势而非只看当期排名。

### 示例 B：结构性差异导致的排名差距

**场景**：京东渠道销售额显著高于其他渠道，主要因为集成灶、烟机等高客单价品类占比更高。

**输出示例**：
> 京东渠道销售额领先其他渠道，但其品类结构中集成灶、烟机等高客单价品类占比达 38%，显著高于其他渠道平均 22% 的水平。排名领先部分源于品类结构差异，而非单纯的渠道运营效率差异，如需评估运营效率建议在同品类结构下做对比。
